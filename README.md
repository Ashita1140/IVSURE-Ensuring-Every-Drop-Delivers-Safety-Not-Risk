# IVSure

## Smart IoT-Based IV Fluid Monitoring System

IVSure is a smart healthcare project developed to continuously monitor the IV fluid level using a Load Cell Sensor and HX711 Amplifier Module. The system measures the weight of the IV bottle in real time and alerts healthcare staff before the bottle becomes empty, helping prevent blood backflow, interruption of medication delivery, and other IV-related complications.

---

## Features

- Real-time IV bottle weight monitoring
- Automatic low IV level detection
- Buzzer alert for critical level
- ESP32 / Arduino based implementation
- Load Cell with HX711 amplifier
- Cost-effective prototype
- Designed for smart healthcare applications

## Working

1. Load Cell continuously measures IV bottle weight.
2. HX711 amplifies sensor readings.
3. ESP32/Arduino processes the weight.
4. When weight reaches the threshold,
5. Buzzer alert is generated.
6. Nurse replaces the IV bottle.
